# Distributed Rate Limiter

A distributed rate limiting system built using Node.js, Redis and Lua.

## Features

- Fixed Window
- Sliding Window
- Token Bucket
- Leaky Bucket
- Redis-backed distributed state
- Lua-based atomic operations
- Consistent Hashing
- Virtual Nodes
- Multi-server architecture

## Tech Stack

- Node.js
- Express
- Redis
- Lua
- Apache Bench

## Learning Outcomes

- Distributed Systems
- Concurrency Control
- Race Conditions
- Atomic Operations
- Consistent Hashing
- Load Balancing
